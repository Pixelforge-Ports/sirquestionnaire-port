Sir Questionnaire - PortMaster testing
Porter: Pixelforge ports (Ronax)

Game: https://www.gog.com/en/game/sir_questionnaire
Package: SirQuestionnaire.zip (BYO data; attach the built ZIP to this post)

Install:
Update PortMaster, put SirQuestionnaire.zip in its autoinstall folder and open PortMaster.
Stay online for the Java 17 and Westonpack downloads if needed.
Supply SirQuestionnaire.jar from your owned Windows build (1.8.5b).
Destination: <ports directory>/sirquestionnaire/SirQuestionnaire.jar.
On muOS: <SD card>/ports/sirquestionnaire/SirQuestionnaire.jar.
Download the full Windows offline installer from your GOG library, install it
on Windows or extract with innoextract, then copy the archive unchanged.
See the installed sirquestionnaire.md for the checksum and manual installation instructions.

Controls:
| Control | Keyboard input / action |
|---|---|
| D-pad up | UP / Up / navigate |
| D-pad down | DOWN / Down / navigate |
| D-pad left | LEFT / Left / navigate |
| D-pad right | RIGHT / Right / navigate |
| A | X / Action / confirm |
| B | ESC / Back / pause |
| X | Z |
| Y | TAB |
| L1 | LEFT / Left / navigate |
| R1 | RIGHT / Right / navigate |
| L2 | F1 |
| R2 | X / Action / confirm |
| Start | O / Options |
| Select | ESC / Back / pause |
| Left stick | Same directions as the D-pad |
| Select + Start | Exit; save through the game first |

Use the game's default keyboard bindings. Start sends **O** for options.
